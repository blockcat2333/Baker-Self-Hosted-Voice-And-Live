# Baker Lite 1.1.2a 更新说明

发布日期：2026-07-27

`1.1.2a` 是与 Baker 服务端 `1.1.2` 配套的 Windows x64 原生轻量客户端，
对应独立 Git 标签 `baker-lite-v1.1.2a`。

## 本次更新

- 将 Baker Lite 公开版本、应用显示版本、安装包版本和更新清单版本统一更新为
  `1.1.2a`。
- 延续 `1.1.1a` 的直播停止按钮、共享音频音量控制和原生 SFU 直播统计修复。
- 与 Baker `1.1.2` 的诊断日志导出和更新代理输入改进保持同一发布线。
- 保持现有 Baker REST、WebSocket、P2P 和 SFU 协议兼容，不需要迁移本地设置。

## 发布资产

- 安装包：`Baker-Lite-Setup-1.1.2a-x64.exe`
- 更新清单：`baker-lite-update.json`
- 支持 Windows 10 1809 及以上版本和 Windows 11，仅支持 x64。
- Windows PE 数字版本为 `1.1.2.1`，FileVersion/ProductVersion 字符串为
  `1.1.2a`。

## 发布前验证

- Release + WebRTC 原生媒体配置构建成功。
- Baker Lite CTest 全部通过。
- NSIS 安装包生成、静默安装和安装后启动冒烟测试通过。
- 安装包 SHA-512 和大小记录在同一 Release 的 `baker-lite-update.json` 中。

## 签名说明

本次安装包没有 Authenticode 签名，Windows 可能显示未知发布者或 SmartScreen
提示。请使用 Release 中的 `baker-lite-update.json` 校验安装包完整性。
