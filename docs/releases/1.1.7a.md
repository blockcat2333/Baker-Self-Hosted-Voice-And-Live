# Baker Desktop 1.1.7a

## Summary

Baker Desktop 1.1.7a is the Windows client paired with Baker server 1.1.7. It
includes the corrected publish-while-watching entry points, explicit start
failure feedback, and the expanded SFU livestream diagnostics interface.

## Compatibility

- Server release: Baker `1.1.7`
- Client release label: `1.1.7a`
- GitHub Release tag: `v1.1.7a`
- Installer: `Baker-Setup-1.1.7a-x64.exe`

The browser/Chromium runtime still chooses hardware or software codec
implementations. The client reports what Chromium exposes but cannot reliably
force either implementation through standard WebRTC APIs.
