# Baker Lite 1.1.1a 更新说明

发布日期：2026-07-27

`1.1.1a` 是 Baker Lite 的首个增量更新版本，对应独立 Git 标签
`baker-lite-v1.1.1a`。本次更新重点改善直播停止操作、共享音频音量控制和原生
SFU 直播统计，同时同步服务端管理端的诊断日志导出能力。

## 产品与界面说明

Baker Lite 是面向 Windows x64 的 Baker 原生轻量客户端。界面的信息密度、
服务器/频道/用户树、菜单和工具栏布局、右键操作以及双击加入语音频道等交互，
借鉴了 TeamSpeak 3 客户端的经典设计思路。

Baker Lite 是独立开发的软件，没有使用 TeamSpeak 的源代码、协议实现、图标或
其他资源，与 TeamSpeak Systems, Inc. 不存在隶属、授权或合作关系。TeamSpeak
及其相关名称和商标归各自权利人所有。

## 本次更新

### 更明显的停止直播操作

- 本机直播成功启动后，主工具栏会立即显示红色“停止直播”文字按钮。
- 停止按钮紧邻屏幕和摄像头直播入口，使用独立的红色停止图标、悬停提示和清晰的
  按下状态。
- 未直播时按钮自动隐藏，避免占用主窗口横向空间；直播结束后按钮立即消失。
- “自己”菜单中的停止直播操作和可配置组合快捷键继续保留。
- 新增 UI 自动化测试，验证按钮的显示条件、强调样式、启用状态和停止信号。

### 共享音频音量

- 屏幕或窗口直播对话框新增独立的“共享音频音量”滑块。
- 直播源声音的初始音量会传递到原生 WebRTC 音频注入链路，并限制在安全范围内。
- 共享音乐来源选择中的音量现在同样传递到原生发布会话，不再只停留在界面状态。
- 屏幕声音、共享音乐和本地播放音量继续保持相互独立。

### P2P 与 SFU 直播质量

- P2P 和 SFU 发布端现在使用用户选择的最大码率与最大帧率，不再使用固定的直播
  编码上限。
- SFU 直播每秒采集一次实际媒体统计，包括编解码器、画面尺寸、FPS、实时码率、
  丢包率、RTT 和质量限制原因。
- 发送端和观看端统计都会通过现有媒体统计信号更新 UI。
- 当直播渲染窗口尚未建立时，本机直播统计仍会显示在底部直播状态区域。
- 增强 SFU Producer/Consumer 统计读取期间的并发保护和停止唤醒逻辑，避免退出
  直播时等待统计轮询超时。

### 配套服务管理改进

本次代码同步还包含服务端管理功能，但不改变 Baker Lite 使用的公开协议：

- 管理端新增“导出诊断日志”按钮。
- 新增仅管理员可访问的运行日志导出接口。
- 导出文件包含运行状态和最近的 all-in-one 容器日志。
- 访问令牌、密码、连接字符串、Cookie 和其他已识别凭据会自动脱敏。
- 导出日志限制最大体积，并同时支持 Docker multiplexed 和普通文本日志格式。
- 更新代理地址支持直接输入 `host:port`，保存时自动补全为 HTTP URL，并继续拒绝
  不受支持的代理协议。

## 版本与兼容性

- Baker Lite 公开版本、应用显示版本、安装包版本和更新清单版本均为 `1.1.1a`。
- 安装包名称：`Baker-Lite-Setup-1.1.1a-x64.exe`。
- 更新清单：`baker-lite-update.json`。
- 支持 Windows 10 1809 及以上版本和 Windows 11，仅支持 x64。
- CMake 和 Windows PE 的固定数字版本字段使用 `1.1.1.1`，Windows 属性页中的
  FileVersion/ProductVersion 字符串显示为 `1.1.1a`。
- Baker Lite 与 Baker Desktop 使用不同的应用 ID、安装目录、设置空间和发布
  标签。
