# Baker 1.0.14

Release date: 2026-07-25

Baker 1.0.14 is a stable server/all-in-one patch release for deployments that edit `MEDIA_REGION_PROFILES` after the container is already running. It fixes deployment apply/update flows so Docker removes stale SFU RTC ports from previous media-region profiles instead of only adding the new range.

## Changes

- Deployment pending markers now store the deployment settings that existed before the first pending edit.
- One-click updates, deployment apply, and runtime self-repair now pass those previous settings to the all-in-one update helper.
- Shrinking or moving a profile-specific SFU RTC range now removes the old Docker port bindings during the replacement container build.
- Added regression coverage for preserving the first pending previous deployment settings across multiple edits.

## Release Artifacts

- Server GitHub Release tag: `v1.0.14`
- Docker images:
  - `blockcat233/baker:1.0.14`
  - `blockcat233/baker:latest`
- Matching desktop GitHub Release tag: `v1.0.14a`

## Upgrade Notes

- Public all-in-one deployments should use `blockcat233/baker:1.0.14` or `latest`.
- After changing `MEDIA_REGION_PROFILES`, click **Apply And Restart Container** so Docker port bindings are rebuilt from the new and previous ranges.
- For dual-region SFU over frp, keep each profile's announced RTC ports reachable at the same public port numbers.
