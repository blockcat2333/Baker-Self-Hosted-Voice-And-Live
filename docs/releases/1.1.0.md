# Baker 1.1.0

Release date: 2026-07-25

Baker 1.1.0 is a stable server/all-in-one release focused on a coherent Discord-inspired experience across the Web client, Windows client, settings surfaces, livestream workflows, and server control panel.

## Highlights

- Reworked the application shell and channel experience around familiar Discord-inspired hierarchy and interaction patterns.
- Added compact grouped right-click menus, submenu behavior, touch long-press equivalents, member actions, and per-participant volume controls.
- Made voice actions more direct with clearer mute/output/leave controls, device-volume menus, connection indicators, and explanatory tooltips.
- Kept member visibility available while livestreaming and made stream entry, viewing, and sender diagnostics easier to discover.
- Preserved Baker-specific advanced stream quality, bitrate, codec, selective application-audio, and network-health controls.
- Restyled settings and the server control panel without introducing unnecessary nested navigation.
- Updated responsive behavior for desktop, tablet, and phone layouts.
- Updated the affected production dependency chain and verified that `pnpm audit --prod` reports no known vulnerabilities.

## Upgrade Notes

- Existing `/var/lib/baker` data remains compatible with this release.
- Pin `blockcat233/baker:1.1.0` for reproducible deployments or use `latest` for the rolling stable image.
- The UI references Discord's interaction model, but Baker uses its own implementation, branding, assets, deployment model, and extended self-hosted controls.
