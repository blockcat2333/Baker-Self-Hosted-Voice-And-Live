# Baker Lite 1.1.3a

## Summary

Baker Lite 1.1.3a is the native Windows client paired with the Baker 1.1.3 server release.

## Compatibility

- Server release: Baker `1.1.3`
- Client release label: `1.1.3a`
- GitHub Release tag: `baker-lite-v1.1.3a`

This client line is compatible with the Aliyun DNS-01 HTTPS entrypoint added to the all-in-one server image.
