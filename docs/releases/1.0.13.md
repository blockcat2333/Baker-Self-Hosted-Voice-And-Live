# Baker 1.0.13

## Summary

Baker 1.0.13 is a stable server/all-in-one patch release for NAS hosts with more than one local IP address. It fixes one-click updates so regenerated Docker port bindings keep the current container's `HostIp` instead of broadening published media ports to `0.0.0.0`.

## Changes

- Preserved the current Docker `HostIp` when regenerating managed Web, TURN, and SFU port bindings.
- New managed media ports inherit the current container's first non-empty `HostIp` when no exact previous binding exists.
- Kept the 1.0.12 stop-before-create update ordering fix.
- Added a regression check for HostIp-preserving port regeneration.

## Upgrade Notes

- Public all-in-one deployments should use `blockcat233/baker:1.0.13` or `latest`.
- This release is relevant when a NAS has Baker bound to one local address, such as `192.168.233.2`, while other NAS services listen on a different local address with the same high media ports.
- Existing data volumes, runtime settings, DSM reverse proxy settings, and router rules are unchanged by this patch.
