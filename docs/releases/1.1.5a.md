# Baker Desktop 1.1.5a

## Summary

Baker Desktop 1.1.5a is the Windows client paired with Baker server 1.1.5. The
client retains the 1.1.4 recovery and multi-server behavior; the matching
server adds stale-WebSocket voice takeover and connection-owned cleanup.

## Compatibility

- Server release: Baker `1.1.5`
- Client release label: `1.1.5a`
- GitHub Release tag: `v1.1.5a`
- Installer: `Baker-Setup-1.1.5a-x64.exe`

Existing 1.1.4 clients remain protocol-compatible with server 1.1.5. Upgrade
both sides when a deployment requires matching release labels and packaged
desktop support.

See the [Realtime Media Recovery Operations Guide](../realtime-media-recovery.md)
for ownership behavior, validation, and rollback details.
