# Baker 1.0.12

## Summary

Baker 1.0.12 is a stable server/all-in-one patch release for Synology and other Docker hosts that expose large TURN/SFU port ranges. It fixes the one-click update helper so replacement containers are created only after the current container has stopped and released its published media ports.

## Changes

- Fixed the all-in-one update helper replacement order.
- The helper now stops the current Baker container and waits for Docker to report it stopped before creating the replacement container with the same published ports.
- Rollback still restores the previous container if the replacement fails to create, start, or become healthy.
- Added a regression test that locks the stop-before-create ordering.

## Upgrade Notes

- Public all-in-one deployments should use `blockcat233/baker:1.0.12` or `latest`.
- This release is especially relevant when a previous update failed with an error like `bind: address already in use` for a published TURN or SFU media port.
- Existing data volumes and runtime settings are unchanged by this patch.
