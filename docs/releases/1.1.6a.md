# Baker Desktop 1.1.6a

## Summary

Baker Desktop 1.1.6a is the Windows client paired with Baker server 1.1.6. It
includes concurrent watch/publish support, strict AV1/VP9/VP8/H.264 selection,
and the expanded SFU livestream diagnostics interface.

## Compatibility

- Server release: Baker `1.1.6`
- Client release label: `1.1.6a`
- GitHub Release tag: `v1.1.6a`
- Installer: `Baker-Setup-1.1.6a-x64.exe`

The browser or operating system still chooses the encoder implementation.
Baker displays whether Chromium reports a hardware-accelerated or software
codec; standard WebRTC does not provide a reliable per-stream force toggle.
