# Baker Desktop 1.1.2a

Release date: 2026-07-27

Baker Desktop 1.1.2a is the Electron Windows client paired with the Baker 1.1.2
server release.

## Highlights

- Aligns the desktop client version with the Baker 1.1.2 server line.
- Includes the current shared Discord-inspired Web/Windows interface, voice and
  livestream controls, network diagnostics, and responsive settings surfaces.
- Includes the shared update-proxy address normalizer used by the server control
  plane.
- Retains the optimized screen/window sharing picker and selective
  application-audio workflow.
