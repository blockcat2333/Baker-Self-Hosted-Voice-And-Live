# Baker Lite 1.1.4a

## Summary

Baker Lite 1.1.4a is the native Windows compatibility release paired with Baker
server 1.1.4. The native client code is unchanged from 1.1.3a; this release
provides matching version metadata and a freshly validated installer for the
1.1.4 server line.

## Compatibility

- Server release: Baker `1.1.4`
- Client release label: `1.1.4a`
- GitHub Release tag: `baker-lite-v1.1.4a`

The new `media.session.reconnect` behavior in 1.1.4 is implemented by the shared
Web/Electron client. Baker Lite continues to use its native media lifecycle and
does not claim the new in-place recovery behavior in this compatibility release.

The release package includes the native P2P/SFU media build, update metadata,
third-party notices, and SHA-512 integrity metadata generated after packaging.
