# Baker Desktop 1.1.8a

The Windows client paired with Baker server 1.1.8 adds automatic PQ/HLG HDR-to-SDR livestream correction, adaptive voice buffering, clipping protection, and corrected participant packet-loss diagnostics.

HDR conversion requires supported Chromium capture APIs and explicit HDR metadata. Unsupported inputs preserve the original stream. Cross-border voice improvements require live listening validation.

- Server release: `1.1.8`
- Client label: `1.1.8a` (package version `1.1.8-a`)
- GitHub tag: `v1.1.8a`
- Installer: `Baker-Setup-1.1.8a-x64.exe`
- Automatic update assets: installer, `.blockmap`, and `latest.yml`
