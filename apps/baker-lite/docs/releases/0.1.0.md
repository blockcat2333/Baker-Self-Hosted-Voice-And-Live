# Baker Lite 0.1.0 更新说明

发布日期：2026-07-26

这是 Baker Lite 的首个公开版本。Baker Lite 使用独立的版本线，本次版本为
`0.1.0`，对应 Git 标签 `baker-lite-v0.1.0`；它不会改变现有 Baker 服务端和
Baker Desktop 的 `1.1.1` 版本线。

## 产品与界面说明

Baker Lite 是面向 Windows x64 的 Baker 原生轻量客户端。界面的信息密度、
服务器/频道/用户树、菜单和工具栏布局、右键操作以及双击加入语音频道等交互，
借鉴了 TeamSpeak 3 客户端的经典设计思路，让熟悉 TS3 的用户可以快速上手。

Baker Lite 是独立开发的软件，没有使用 TeamSpeak 的源代码、协议实现、图标或
其他资源，与 TeamSpeak Systems, Inc. 不存在隶属、授权或合作关系。TeamSpeak
及其相关名称和商标归各自权利人所有。

## 本次发布内容

### 原生客户端架构

- 使用 C++20、Qt 6.8.3 Widgets、CMake 和 Visual Studio 2022 构建。
- 不包含 Electron、Node.js、React、Chromium、QML、Qt Quick 或 Qt WebEngine
  运行时。
- 使用 Qt Network 和 Qt WebSockets 连接现有 Baker REST API 与 WebSocket
  信令，不要求服务端进行破坏性协议升级。
- 原生媒体构建固定使用 libmediasoupclient 3.5.0、libwebrtc m140 和
  libsdptransform 1.2.10。

### TS3 风格的主界面与操作

- 提供原生菜单栏、工具栏、服务器频道树、详情区、频道聊天、服务器/连接日志和
  状态栏。
- 支持单击频道切换聊天、双击语音频道加入，以及频道、用户和直播相关右键菜单。
- 主窗口支持横向缩窄，右侧详情区不再占用过多宽度；直播观看使用独立弹出窗口。
- 工具栏按钮均提供功能提示，麦克风、扬声器和共享音乐播放音量按钮支持点击静音；
  鼠标悬停时可以直接使用音量滑块。
- 加入频道、离开频道、麦克风静音、扬声器静音以及开始/停止直播等状态变化提供
  声音提示。
- 窗口尺寸、分隔条位置、语言和用户偏好通过 `QSettings` 保存。

### 账户、服务器与书签

- 登录界面提供注册入口，支持登录、注册、退出登录和令牌刷新。
- 支持服务器地址规范化、连接检测、保存服务器以及从“书签”菜单快速切换服务器。
- 书签可以选择保存账号；保存密码时仅写入 Windows Credential Manager，不在
  配置文件中保存明文密码。
- 访问令牌仅保存在进程内存中，刷新令牌和记住登录资料使用 Windows Credential
  Manager。

### 文字频道与在线状态

- 支持 Guild、文字/语音频道、成员与在线状态同步。
- 支持消息历史、历史分页、实时消息、发送消息和搜索。
- 聊天消息现在同时显示日期和时间，格式为 `yyyy-MM-dd HH:mm`。
- 频道树显示在线、静音、发言、音乐、直播和连接质量状态。
- 当用户网络连接异常时，会在用户名后以括号文字明确显示异常状态，替代难以理解的
  数字状态标记。

### 原生语音

- 支持 libwebrtc P2P 连接、SDP/ICE 信令、ICE restart 与断线恢复。
- 支持 libmediasoupclient SFU Device、发送/接收 Transport 以及
  Producer/Consumer。
- 支持加入、离开和切换语音频道、发言检测、设备热切换、主音量和单用户音量。
- 单用户音量使用右键菜单中的滑块调节。
- 麦克风与扬声器设备统一放在设置对话框中管理。
- 离开语音频道后立即清理本地频道状态，避免界面继续显示仍在语音频道中。

### 共享音乐

- 使用原生 Windows process-loopback 捕获选定进程树的声音，并排除 Baker Lite
  自身进程树。
- 音乐来源选择界面实时显示每个候选进程的音量电平。
- 共享音乐开关与共享音乐播放音量使用不同图标，播放音量按钮带有明确的音量标识。
- 共享音乐播放音量支持独立滑块、点击静音/取消静音，以及快捷键增减。
- 支持 P2P 与 SFU 媒体模式下的音乐发送和监听状态恢复。

### 屏幕、窗口与摄像头直播

- 使用 libwebrtc DesktopCapturer 捕获屏幕和窗口，使用 VideoCaptureModule
  捕获摄像头，不依赖 Qt Multimedia 或浏览器视频组件。
- 开始直播对话框显示屏幕、窗口和摄像头来源名称，并提供可更新的来源预览。
- 修复点击“开始直播”后没有反应的问题；选定来源后会进入原生捕获与媒体发布流程，
  失败时显示可诊断错误。
- 支持屏幕、窗口和摄像头来源，以及分辨率、帧率、码率和编解码器偏好。
- 直播使用独立原生窗口观看，支持全屏、关闭观看和每路播放音量控制。
- 正在直播的 `LIVE` 状态使用红色突出显示，便于从频道树快速发现并打开直播。
- 支持直播断线恢复以及编码、分辨率、FPS、码率和丢包统计。

### 快捷键

所有快捷键默认不绑定，并支持组合键。设置页可配置：

- 连接服务器、断开服务器和离开语音频道。
- 按键说话。
- 静音/取消静音麦克风、扬声器和共享音乐播放。
- 分别调低或调高麦克风、扬声器和共享音乐播放音量。
- 停止当前直播。

### 安全、日志与更新

- 严格解析 Baker REST/WS JSON 数据，缺少必填字段时进入可诊断错误状态。
- WebSocket 支持 ACK 关联、超时、心跳、指数退避重连和全量状态恢复。
- 日志自动过滤访问令牌、刷新令牌、密码、ICE 凭据和敏感请求头。
- 更新器只识别包含 `baker-lite-update.json` 的 Baker Lite Release，不会把 Baker
  服务端或 Desktop Release 误识别为 Lite 更新。
- 下载更新后校验 SHA-512，再启动按用户安装的 NSIS 安装程序。

- 支持 Windows 10 1809 及以上版本和 Windows 11，仅支持 x64。
- 安装包名称：`Baker-Lite-Setup-0.1.0-x64.exe`。
- 更新清单：`baker-lite-update.json`。
- 本次安装包没有 Authenticode 签名，Windows 可能显示未知发布者或
  SmartScreen 提示；发布资产中的 SHA-512 清单可用于校验文件完整性。
- Baker Lite 与现有 Baker Desktop 可以并存，使用独立的应用 ID、安装目录和
  设置空间。
