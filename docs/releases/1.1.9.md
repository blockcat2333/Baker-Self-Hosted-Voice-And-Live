# Baker 1.1.9

## Changes / 更新内容

- Optional RNNoise microphone noise suppression in Web and Desktop. Ordinary browser suppression remains the default; users can switch manually and their choice is remembered. Processing runs locally with bundled WebAssembly and AudioWorklet. Echo cancellation and automatic gain control remain enabled; failures fall back to ordinary suppression. / 网页和桌面端新增可选 RNNoise，默认普通降噪，支持手动切换、记忆选择及故障回退。
- Improve voice and livestream recovery after temporary ICE or gateway disconnections, clean up failed consumers for retry, and keep shared music volume controls available during reconnection. Existing livestream bitrate defaults are preserved. / 改善语音和直播断线恢复，保留原有默认直播码率和共享音乐音量入口。
- Web builds detect newer deployments and offer a manual refresh. Container entry pages avoid stale caching; missing assets return 404. / 网页检测新构建并提示手动刷新，避免入口缓存和资源错误返回 HTML。

## Artifacts and upgrade / 产物与升级

- Server tag: `v1.1.9`; Windows client: `v1.1.9a`.
- Docker Hub: `blockcat233/baker:1.1.9` and `blockcat233/baker:latest`.
- GHCR: `ghcr.io/blockcat2333/baker:1.1.9` and `ghcr.io/blockcat2333/baker:latest`.
- Upgrade the image while preserving the existing data volume and environment configuration. Refresh existing browser tabs once, and install Desktop 1.1.9a for desktop microphone processing. No new server setting or database migration is required. / 保留数据卷和环境配置更新镜像；旧网页首次需手动刷新，桌面端安装 1.1.9a，无新增数据库迁移。
- Roll back by restoring image 1.1.8 and Desktop 1.1.8a. Roll back complete web assets and static-server configuration together. / 可回滚至 1.1.8 / 1.1.8a，网页资源与静态服务器配置需一起回滚。

## Validation and limits / 验证与边界

- 57 test files, 304 tests; workspace typecheck and lint; production builds; real Edge production-worklet and fake-microphone UI smoke tests, including actual capture flags, switching, fallback and 390px layout.
- Container publishing performs all-in-one service health and Web/Admin HTTP smoke tests. Windows installer assets are built by the desktop workflow.
- RNNoise requires a secure web context, WebAssembly and AudioWorklet. Switching briefly reacquires the microphone. Human listening quality, real congested-network calls, Safari/Firefox and mobile background/power use remain field-validation items.
- Production dependency audit reports 11 existing advisories (7 high, 3 moderate, 1 low) in the dependency tree. This release does not claim to resolve them; RNNoise is not among the reported packages.
