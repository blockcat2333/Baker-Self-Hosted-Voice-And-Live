# Baker Desktop 1.1.9a

Windows x64 client for Baker 1.1.9 (`1.1.9-a` package version).

- Adds optional local RNNoise microphone suppression. The default remains ordinary suppression; choose RNNoise in microphone controls to enable it. Failed initialization or processing restores ordinary suppression.
- Improves voice and live recovery and keeps music mute/volume controls available while reconnecting. Livestream bitrate defaults are unchanged.
- Installer: `Baker-Setup-1.1.9a-x64.exe`; updater metadata: `latest.yml`; companion `.blockmap` supports updates.
- Install or use the existing updater. Update the server to 1.1.9 for the paired recovery changes. No new configuration is required. Reinstall 1.1.8a if rollback is needed.
- Validation: 304 workspace tests, typecheck, lint, production builds and real Edge Worklet/UI smoke. Human microphone quality and long-running CPU/power measurements remain unverified.

新增可选 RNNoise，默认不开启；改善语音/直播恢复并保留音乐音量入口。支持安装或现有更新器升级，建议服务端同步升级至 1.1.9；必要时重新安装 1.1.8a 回滚。
