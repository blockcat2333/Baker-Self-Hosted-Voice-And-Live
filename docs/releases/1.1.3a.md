# Baker Desktop 1.1.3a

## Summary

Baker Desktop 1.1.3a is the Electron Windows client paired with the Baker 1.1.3 server line.

## Compatibility

- Server release: Baker `1.1.3`
- Client release label: `1.1.3a`
- GitHub Release tag: `v1.1.3a`
- Installer: `Baker-Setup-1.1.3a-x64.exe`

The client can connect to both regional Baker entrypoints. Browser users still require a trusted HTTPS endpoint; the server's optional Aliyun DNS-01 listener provides that endpoint when Baker is exposed through a nonstandard FRP TCP port.
