# Baker 1.1.2

Release date: 2026-07-27

Baker 1.1.2 is a stable server/all-in-one release focused on support diagnostics,
more forgiving update-proxy configuration, and the matching Windows client line.

## Highlights

- Added an administrator-only diagnostic log export to the server control panel.
- Included runtime health, host/container metadata, and the latest 10,000
  all-in-one container log lines in a timestamped text download.
- Added automatic redaction for passwords, tokens, authorization headers,
  cookies, database URLs, and other recognized credentials.
- Limited exported container logs to the newest 5 MiB and retained a useful
  diagnostic summary when Docker logs are unavailable.
- Allowed update proxies to be entered as `host:port`, `IP:port`, or
  `//host:port`; Baker now adds `http://` automatically.
- Kept explicit validation for unsupported proxy protocols.
- Made first-run server settings and shared-workspace initialization safe when
  multiple users register concurrently.

## Upgrade Notes

- Existing `/var/lib/baker` data remains compatible with this release.
- Mount `/var/run/docker.sock` into the all-in-one container to include complete
  container logs in diagnostic exports. Without it, exports still contain the
  available runtime health summary and explain why container logs are absent.
- The optional update proxy applies to Baker update metadata requests. Docker
  image pulls still use the host Docker daemon network configuration.
