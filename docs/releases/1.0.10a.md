# Baker Desktop 1.0.10a

## Summary

Baker Desktop 1.0.10a is the Windows desktop client release matching the stable Baker 1.0.10 server line. It carries the same desktop feature set as the previous 1.0.9a client while aligning updater metadata and installer naming with the 1.0.10 stable server release.

## Changes

- Bumped Electron package metadata to semver `1.0.10-a`.
- Published the public desktop/client label as `1.0.10a`.
- Updated the Windows installer artifact name to `Baker-Setup-1.0.10a-x64.exe`.
- Kept desktop updater compatibility with GitHub Releases and lettered desktop tags.
