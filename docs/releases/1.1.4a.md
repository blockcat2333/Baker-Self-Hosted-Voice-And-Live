# Baker Desktop 1.1.4a

## Summary

Baker Desktop 1.1.4a is the Windows client paired with Baker server 1.1.4. It
adds resilient Gateway and media-session recovery plus a race-safe multi-server
switcher.

## Changes

- Preserves voice, stream, and shared-music intent across transient disconnects.
- Shows escalated recovery incidents after five failures while continuing
  bounded automatic retries.
- Supports immediate retry and explicit abandon without stale task completion
  corrupting the active session.
- Detects half-open Gateway connections and reconnects automatically.
- Saves multiple Baker server entries and probes API, identity, and Gateway
  health before switching.
- Keeps the current server active when target validation fails.
- Encrypts per-server sessions with Electron `safeStorage` when available and
  uses memory-only sessions otherwise.

## Compatibility

- Server release: Baker `1.1.4`
- Client release label: `1.1.4a`
- GitHub Release tag: `v1.1.4a`
- Installer: `Baker-Setup-1.1.4a-x64.exe`

The complete in-place recovery protocol requires server 1.1.4. Against an
older server, the client uses compatible legacy recovery behavior where
available.

See the [Realtime Media Recovery Operations Guide](../realtime-media-recovery.md)
for storage, compatibility, validation, and troubleshooting details.
