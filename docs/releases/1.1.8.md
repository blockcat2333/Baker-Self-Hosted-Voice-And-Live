# Baker 1.1.8

## Livestream HDR and voice quality

- Web and Electron capture automatically convert explicitly identified PQ/HLG HDR frames to SDR before publishing, with shared processing for P2P and SFU streams.
- HDR status is visible in the stream panel. SDR passes through; unsupported capture APIs, frame formats, or missing HDR metadata preserve the original stream. Tone mapping uses fixed reference levels rather than measured display calibration.
- Voice receivers adapt their jitter-buffer target to delayed packets and audible concealment. Opus voice publishing enables FEC and disables DTX.
- Smooth gain changes and a soft limiter reduce clipping when microphone or listener volume is amplified.
- Participant diagnostics show actual available packet-loss feedback, jitter, discarded packets, buffer delay and audible concealment. Missing feedback remains unavailable, fractional loss is preserved, and stale reports expire.

These changes improve resilience and observability; the intermittent overseas voice issue still requires a live cross-border listening check to confirm resolution.
