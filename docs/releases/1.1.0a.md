# Baker Desktop 1.1.0a

Release date: 2026-07-25

Baker Desktop 1.1.0a is the Windows client paired with the Baker 1.1.0 server release.

## Highlights

- Uses the same Discord-inspired shared client shell as the Web application.
- Aligns login, startup, update, settings, voice, member, and livestream surfaces with the neutral dark/purple Baker visual system.
- Rebuilds the screen/window sharing picker with previews, source tabs, selected-state feedback, search, and optional system audio.
- Rebuilds the selective application-audio picker with search, privacy guidance, live level meters, selected-source summary, and responsive sizing.
- Retains Baker's extended livestream quality choices and voice/livestream network diagnostics.
- Includes the patched desktop update dependency chain used by the shared 1.1.0 security baseline.
